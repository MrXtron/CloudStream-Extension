# 🌐 About This Extension

### 🎬 Stream Smarter. Buffer Less.
The ultimate multi-source provider extension for Cloudstream. Enjoy a clean, fast, and completely automated viewing experience across all your favorite platforms.
### ✨ Highlights
* ⚡ **Ultra-Fast:** Instant scraping with minimal resource footprint.
* 🧼 **Zero Bloat:** Clean streams with smart domain optimization.
* 🔄 **Auto-Sync:** Links are regularly refreshed and validated.


# 🚀 Getting Started

### 🎯 Requirements

Cloud Stream ( To install : [View Docs](https://recloudstream.github.io/csdocs/) )

### 🛠 To Install Repo

1) **Short code** : `xtronrepo` 
2) **Short URL** : https://py.md/xtronrepo
3) **Manual Install** (Copy and Paste in add Repo of Cloud Stream) :
